# 输出格式

## 默认短版

默认使用以下 Markdown 模板：

```markdown
## 告警研判结果

### 结论

### 风险等级

### 检测到的特征
| 特征项 | 值 |
| --- | --- |

### 判断说明

### 影响判断

### 建议动作
```

写作要求：

- 结论只能用简洁人话表达：误报 / 正常行为 / 攻击尝试 / 攻击成立 / 待进一步确认。
- 风险等级仅用：高 / 中 / 低。
- 检测到的特征写 2 到 4 个关键字段或特征值。
- 判断说明必须解释为什么这些特征支持当前结论，避免只罗列字段。
- 影响判断只回答有没有出事、目前影响到什么程度。
- 建议动作最多 3 条，必须可执行。
- 行为检出告警需说明 `threat.level` 类型并建议确认授权行为。

无 pcap 时必须附加证据来源说明：

```markdown
> 无 pcap，当前结论基于 JSON 告警字段研判。
>
> 是否有对应的 pcap 文件？如有请提供路径，可做进一步验证。
```

## 必要长版

仅在以下情况使用长版：

- 用户明确要求完整分析过程。
- 结论存在争议，需要复核。
- 需要给安全人员做二次判断。
- 需要保留完整证据链。

长版模板：

```text
【最终结论】
【告警类型】
【触发原因】
【流量事实】
【行为成立性】
【攻击目的性】
【业务合理性】
【处置建议】
```

## 输出约束

- 默认优先使用短版。
- 不得把“触发原因”写成“最终结论”。
- 无 pcap 时，必须明确写出“无 pcap，当前结论基于 JSON 告警字段研判”。
- 无 pcap 但存在强结果性证据时，可以输出“攻击成立”或“利用成功”；否则不得输出强结论。
- 不得使用过多安全术语堆砌非必要细节。
- 溯源报告必须直接输出给用户，禁止仅保存到本地文件。
