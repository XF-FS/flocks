# 高危调用类告警

## 适用范围

命中以下内容时读取本规则：

- 命令执行
- SQL 存储过程、OLE、UDF、CLR 高危调用
- 脚本执行
- 高危对象创建与方法调用
- 任意高危函数名、对象名、方法名命中类告警

禁止仅凭函数名、对象名或方法名直接定性。

## 追加五项判断

### 1. 能力对象识别

说明命中的对象、函数、组件是什么，以及能力类型：

- 文本 / 正则处理
- 系统命令执行
- 文件写入 / 落地
- 网络访问 / 下载
- 脚本解释 / 动态执行
- 其他业务组件能力

示例：

- `VBScript.RegExp`：文本 / 正则处理
- `WScript.Shell`：系统命令执行
- `ADODB.Stream`：文件写入
- `MSXML2.XMLHTTP` / `WinHttp.WinHttpRequest`：网络访问
- `child_process.execSync` / `Runtime.exec`：系统命令执行

### 2. 方法动作识别

区分仅创建对象 / 初始化能力，还是已调用具体动作。

仅创建对象通常只能说明具备能力，不等于攻击成立；已调用 `Run`、`Exec`、`SaveToFile`、`Write`、`Open`、`Send` 等动作时，风险显著上升。

### 3. 参数语义识别

判断参数更像正常业务数据还是攻击载荷。重点关注：

- `cmd.exe`、`powershell`、`bash`、`sh`
- `wget`、`curl`、`certutil`、`bitsadmin`
- URL / 外联地址
- 文件路径、`.exe`、`.dll`、`.ps1`、`.vbs`
- 编码后的脚本 / 可执行片段
- 正则表达式、普通字符串、业务查询语句等低攻击性内容

### 4. 结果证据核验

确认是否看到命令回显、下载成功、文件落地、子进程启动、回连建链、异常成功响应等结果性证据。

无结果性证据时，不得仅凭“高危函数 + 可疑参数”判“攻击成立”，最多判为“攻击尝试 / 可疑攻击行为”或“待进一步确认”。

### 5. 业务合理性校验

判断对象、方法、参数组合是否可能由正常业务产生，例如：

- SQL Server 中 `VBScript.RegExp` 做字符串 / 正则处理
- 管理平台正常调用系统命令封装运维任务
- SCCM / Configuration Manager 正常协议报文
- 自动化脚本 / 调度系统的合法命令调用

## 整合原则

分析流程不变：字段提取 → pcap / 上下文验证 → 模型研判 → 模板输出。

研判逻辑从“高危函数命中”升级为“对象 / 函数 + 方法 + 参数 + 结果证据 + 业务合理性”的行为链判断。
