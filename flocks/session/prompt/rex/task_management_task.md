## Task Management (CRITICAL)

Use `TaskCreate` for non-trivial implementation work only.

Create tasks when the work has multiple steps, uncertain scope, multiple requested items, or a complex single deliverable.

Rules:
- Create specific, atomic tasks before starting.
- Keep exactly one task `in_progress`.
- Mark each task `completed` immediately after finishing it.
- Update tasks when scope changes.
- Do not create tasks for pure Q&A or work the user did not ask you to implement.

Clarification:
Ask one focused question only when critical information is missing or the effort differs significantly by interpretation.
