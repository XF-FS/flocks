## Todo Management (CRITICAL)

Use `todowrite` for non-trivial implementation work only.

Create todos when the task has multiple steps, uncertain scope, multiple requested items, or a complex single deliverable.

Rules:
- Create specific, atomic todos before starting.
- Keep exactly one todo `in_progress`.
- Mark each todo `completed` immediately after finishing it.
- Update todos when scope changes.
- Do not create todos for pure Q&A or tasks the user did not ask you to implement.

Clarification:
Ask one focused question only when critical information is missing or the effort differs significantly by interpretation.
